7. Android NDK/LLVM runtime and Android system libraries
------------------------------------------------------
Built with Android NDK r30 (30.0.16248370). The native link uses
-static-libstdc++, so LLVM libc++/libc++abi and toolchain support notices are
included from the installed NDK's verbatim NOTICE / NOTICE.toolchain files.
These contain the applicable LLVM/Apache exception and other runtime terms;
they also include broader toolchain notices for completeness. Toolchain
executables and runtime installations are not bundled in the source archive.

The application dynamically uses device-provided libc, libm, liblog, libdl,
libEGL, libGLESv3, libandroid and libaaudio. These system libraries are not
copied into the APK or the source bundle. See licenses/Android-NDK-NOTICE.txt
and Android-NDK-NOTICE.toolchain.txt.

8. Components absent from this release
-------------------------------------
ANGLE, Turnip/Mesa, AdrenoTools, their custom-driver binaries and SDL are not
linked or packaged in the system-GLES release. Historical optional backend
source may remain in the code snapshot but is disabled by
NHL07_CUSTOM_GRAPHICS=OFF; its separate prebuilt dependencies are not included.
Development-only Python/Pillow/fonttools/CMake/Java/NDK installations are not
redistributed. Install them separately under their own license terms.
